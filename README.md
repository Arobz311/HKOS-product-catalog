# HK Official Store Product Catalog
Website katalog produk **HK Official Store by Harapan Kurnia Textile Indonesia (HKTI)**.

## File
- `index.html` — struktur halaman
- `style.css` — tampilan responsif
- `script.js` — data produk, pencarian, filter, detail, dan format inquiry
- `images/` — folder untuk foto produk asli

## Upload ke GitHub
1. Buka repository `HKOS-product-catalog`.
2. Pilih **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, dan `README.md`.
4. Klik **Commit changes**.

## Aktifkan GitHub Pages
1. Buka **Settings → Pages**.
2. Pada Build and deployment, pilih **Deploy from a branch**.
3. Pilih branch `main` dan folder `/ (root)`.
4. Klik **Save**, tunggu deployment selesai.

## Catatan penting sebelum publikasi
- Kartu produk saat ini menggunakan ilustrasi tekstur generik. Ganti dengan foto kain asli di folder `images/` untuk katalog final.
- Data produk merupakan daftar ringkas portofolio. GSM, lebar, komposisi, MOQ, harga, dan stok tidak dicantumkan karena perlu dikonfirmasi per artikel.
- Verifikasi kembali nama artikel, klaim performa, merek dagang, sertifikasi, statistik perusahaan, dan ketersediaan sebelum publikasi.
- Instagram: https://www.instagram.com/hk.official.store/
- Form inquiry hanya menyalin teks; website ini belum memiliki backend atau penyimpanan inquiry.
- Google Fonts memerlukan koneksi internet.

## Uji lokal
Jalankan `python -m http.server 8000` dari folder project, lalu buka `http://localhost:8000`.
